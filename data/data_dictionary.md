# Data Dictionary — Synthetic Micro-Stoppage Dataset

The dataset is generated by [`src/generate_data.py`](../src/generate_data.py) with a
fixed seed (`42`), so it is fully reproducible. It simulates ~3 weeks of machine-state
events for a high-mix contract manufacturer across 4 machines and 3 shifts.

## `events.csv` — raw machine-state event log

| Column | Type | Description | Example |
|---|---|---|---|
| `ts` | datetime | Event timestamp | `2026-07-01 06:14:02` |
| `machine_id` | string | Asset identifier | `CNC-02` |
| `machine_state` | string | One of `SETUP`, `RUNNING`, `STOPPED`, `IDLE` | `STOPPED` |
| `product_id` | string | Product being run | `P-4471` |
| `customer_id` | string | Owning customer | `CustA` |
| `shift` | string | `A` (06–14), `B` (14–22), `C` (22–06) | `A` |
| `operator_note` | string | Free-text note (may be empty, shorthand, or multilingual) | `matl jam again` |

A **stoppage** is derived from a `RUNNING → STOPPED/IDLE → RUNNING` sequence; its
duration is the gap. A **micro-stoppage** is a stoppage between the debounce floor
(2 s) and the micro ceiling (300 s), both configurable in `config.yaml`.

## `ground_truth.csv` — planted recurring patterns (for scoring only)

The generator injects known recurring causes so the miner can be measured. The
pipeline never reads this file; only [`src/evaluate.py`](../src/evaluate.py) does.

| Column | Description |
|---|---|
| `machine_id`, `product_id`, `shift` | Context the pattern lives in |
| `cause` | Canonical cause planted |
| `after_setup_min` | If set, the cause fires only within N min of a setup |
| `label` | Human-readable description |

### Planted patterns

| Machine | Product | Shift | Cause | Character |
|---|---|---|---|---|
| CNC-02 | P-4471 | A | material_jam | frequent, **setup-driven** (fires soon after changeover) |
| PRESS-01 | P-8810 | B | misfeed | frequent |
| PACK-01 | P-2200 | C | sensor_fault | frequent, **night shift** |
| CNC-01 | P-4472 | A | tool_change | **rare but costly** (long duration) — tests E5 ranking |

## Deliberately injected messiness (drives the edge cases)

| Condition | How it appears | Edge case |
|---|---|---|
| Empty notes | `operator_note == ""` for some stoppages | E1 |
| Shorthand / typos / other languages | `matl jam`, `jamd`, `atasco`, `alimentacion mala` | E2 |
| Sensor chatter | Sub-second `STOPPED→RUNNING` blips | E3 |
| New customer (CustD / P-9000) | Appears only in the final 2 days | E4 |
| Rare-but-costly cause | Long tool-change stoppages, low frequency | E5 |
| Background noise | Random causes spread thin across contexts | (must NOT form findings) |
